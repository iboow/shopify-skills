# Rédiger une proposition publiable

Relever les faits utilisables, leur source et leur portée (produit ou variante). Choisir la question d’achat à résoudre. Écrire dans la langue demandée en conservant noms de gamme, unités, distinctions de variantes et ton de la boutique. Séparer les textes prêts à relire des demandes de confirmation.

| Livrable | Construction |
|---|---|
| Titre produit | Type de produit + modèle + attribut de choix attesté. Garder le nom propre reconnaissable. |
| Description | Ouvrir sur le produit et son usage documenté. Grouper les caractéristiques qui aident à choisir. Pour une fiche simple, une phrase précise suffit. |
| Bénéfices | Relier un fait à son utilité directe. Une capacité de 300 ml permet d’évaluer la portion. Elle ne prouve aucune performance thermique. |
| Objections et FAQ | Répondre avec une valeur vérifiée. Déplacer les questions sans réponse dans « À confirmer », hors du texte publiable. |
| SEO | Suivre le référentiel SEO. Adapter les formulations au lecteur qui voit le produit pour la première fois. |
| Offre | Proposer un tableau de variantes si leurs attributs diffèrent. Préciser les données nécessaires avant toute suggestion de lot ou de remise. |

Pour chaque proposition, fournir le champ cible, le texte et les champs sources. Relire chaque promesse contre ces sources. Ne créer ni caractéristique, avis, certification, garantie, réduction, disponibilité ni condition de livraison. Ne jamais déduire « fait main » d’une matière, ni « compatible lave-vaisselle » d’une photo.
