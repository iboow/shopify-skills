# Examiner le texte de recherche

Lire séparément titre produit, titre SEO personnalisé, description produit et méta-description. Si un champ personnalisé est vide, proposer une rédaction dédiée. Le moteur ou le thème peut générer un texte de remplacement. Le snippet affiché, l’indexation, le classement et le trafic nécessitent des preuves distinctes.

Identifier l’expression principale à partir du type de produit, puis une précision utile issue des données (matière, format, compatibilité attestée). Vérifier que titre, introduction et intertitres éventuels répondent à la même intention. Conserver la langue du marché. Éviter les répétitions forcées. Ne donner aucun volume de recherche sans mesure.

Comparer les champs normalisés (espaces, casse) des ID récupérés pour repérer les textes identiques. Exclure les champs vides du décompte des doublons et citer les ID concernés. Traiter séparément les traductions. Restreindre toute conclusion de singularité au lot observé.

Rédiger un titre distinctif et une méta-description autonome qui annonce un détail de choix. Relire les premiers mots en cas de troncature. La longueur reste un contrôle éditorial, sans garantie d’affichage.
